# Mini-Monopoly Code

### Copy over your code
Copy/paste your mini-monopoly code into the *Vexcode_monopoly.py* file.


### Init your repo
First, make a new repository on GitHub for this project.
Then use Tools > Git > Remotes... to initialize your repository using the SSH link from GitHub.

### Commit your code
Open the terminal and use *git add Vexcode_monopoly.py* and then *git commit -m "init project"* to stage your commit.
Finally, use *git push* to push your commit over to GitHub.
